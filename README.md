I'm Joseph, a mathematician and computational linguist who builds software for writing. I made [Vale](https://github.com/vale-cli/vale), a linter that treats prose like code, and [prose](https://github.com/jdkato/prose), an NLP library for Go that's built into Hugo. I also write [data stories](https://jdkato.io/stories) about language, law, and sports.
